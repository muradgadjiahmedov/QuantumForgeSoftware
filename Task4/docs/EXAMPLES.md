# Примеры диалогов

## Успешные ответы
**Q:** Что такое Void Core и кто его использует?  
**A:** Void Core — мегаструктура Dominion, применяемая как орудие звёздного масштаба. [void_core#chunk=12; dominion#chunk=25]

**Q:** Как работать с Flux Compass в нестабильных зонах?  
**A:** Используйте Flux Compass для определения узлов резонанса Synth Flux и избегайте «немых» карманов. [flux_compass#chunk=5; umbral_current#chunk=8]

**Q:** Кто такой Xarn Velgor?  
**A:** Стратег Shadow Order, практик Umbral Current, связанный с операциями на Velis. [xarn_velgor#chunk=0; shadow_order#chunk=14]

**Q:** Какую роль играет Aurion Pact в конфликте?  
**A:** Коалиция свободных систем, ведущая переговоры и рейды против Dominion. [aurion_pact#chunk=21]

**Q:** Что такое Photon Blade?  
**A:** Лучевой клинок с настраиваемым резонатором под владельца. [photon_blade#chunk=9]
